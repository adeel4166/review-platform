# 04 Compare page

Route `/compare?ids=a,b,c`. 2–4 products (v2/ADR-0032 limits unchanged). Intro: `h1` "Compare products", `gradient-brand-soft` header wash, `text-muted` helper "Add up to 4 products".

## Layout
| Breakpoint | Pattern |
|---|---|
| ≥lg | Real `<table>` with `<caption>` (sr-only), sticky first column (feature names, inline-start) and sticky header row (product cards). Column min-width 14rem, the table scrolls inside a labelled region (`role=region tabindex=0 aria-label="Product comparison"`) only when >3 columns at <xl |
| <lg | Swipeable column pair: show 2 products side by side with a product selector (two `Select`s "Compare {A} with {B}"), other products reachable via the selector. No horizontal page scroll |

## Header cells (product)
Compact ProductCard head (02): image 6rem `radius-lg`, name `text-h3` (2 lines), Stars + number, "Remove {name}" button (X, 44px with text label on ≥md), primary "View product". **Best-value / highest-rated** highlight: `primary-subtle` column tint + a text badge "Highest rated" (Trophy icon + text); never tint alone. Winners computed per row: cell shows check icon + text via `sr-only` "Best in this row".

## Row groups (`<tbody>` each with `<th scope="rowgroup">`)
1. **Overview:** rating, review count, verified share, trust score, price range
2. **AI summary:** per-product short pros/cons (from 03 AI card; "No summary yet" when absent; "Generated by AI" label once in the group header)
3. **Rating distribution:** mini histogram bars (`star` fill 3:1) + numeric %, table-alternative values always in text
4. **Specs / attributes** (union of attributes, missing = "Not listed" in `text-muted`, never blank)
5. **Differences only** toggle (Switch with text label, `aria-checked`): hides equal rows, result in `role=status` "12 rows hidden"
Row header `th scope="row"` is `text-small font-semibold`, never truncated, wraps.

## Sticky compare bar (floating, from product/listing pages)
`.glass-strong`, `radius-2xl`, `elevation-3`, bottom-centre, max `layout-content-max`; contains selected thumbs (with remove), "Compare ({n})" primary button (disabled with explanation `aria-describedby` when <2), "Clear". `role=region aria-label="Compare tray"`, announces adds via `role=status`. Solid `surface` fallback (forced-colors / reduced-transparency). Does not cover content: `scroll-padding-bottom` + page padding equal to the bar height; hidden when the keyboard-visible focus would be obscured (WCAG 2.4.11).

## Add product
Last empty column = dashed `border` button "Add a product" → opens command palette (05) in "products" mode / Dialog search; focus returns to the button.

## States
Loading (table skeleton with same columns), <2 valid ids (EmptyState "Pick at least two products" + search), product removed/unavailable (column shows "No longer listed", row values "—" with sr text), error (state kit), >4 (toast `warning`: "You can compare up to 4").

## Theme / RTL / i18n
Sticky column on inline-start (mirrors); winner tint `primary-subtle` with `on-primary-subtle`/`text` gated in both themes; bars fill from inline-start; feature names wrap at +40 %; numbers `tabular-nums` in `<bdi>`; no truncation of attribute names or values (user data wraps with `break-words`).

## A11y
Table semantics (`caption`, `scope`), sticky header does not hide focused cells (`scroll-margin`), column removal returns focus to the next column's remove button or the "Add" button; the tray and page share one source of truth; keyboard: Tab through header actions then rows (no custom roving required); motion: column add/remove fade `base`, none under reduced motion.
