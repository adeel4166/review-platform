# 03 Product page: gallery, rating histogram, AI summary card

Route `/products/[slug]`. Layout ≥lg: 12 col, left `col-span-7` gallery, right `col-span-5` summary panel (sticky `top` = `header-height` + `space-4`, **not** sticky when its height > viewport); reviews below full-width with filters. Base: stacked, sticky bottom CTA bar (glass, "Write a review", safe-area aware).

## Gallery (ADR-0034 D9/D11)
| | Spec |
|---|---|
| Main stage | aspect `placeholder-aspect-gallery` (4/3) ≥md, 1/1 base; `radius-2xl`, `bg-subtle`, `ring-1 ring-inset ring-border`; `next/image` `fill`, `object-contain` (never crop product photos), first image `priority`, `sizes="(min-width:1024px) 58vw,100vw"` |
| Thumbs | row (base) / column (≥xl, start side) of 4rem squares, `radius-lg`, max 6 visible then scroll-snap; selected = 2px `primary` border + `aria-current="true"`; each is a button "Show image {n} of {total}: {alt}" |
| Slide change | native scroll-snap on the stage (swipe) **plus** Prev/Next buttons (44px, `glass`-free solid `surface` circles, `rtl:` mirrored) and thumbs; counter "3 of 8" in a visible chip + `aria-live=polite` region. Cross-fade `base` (opacity only); under reduced motion, instant. No autoplay (WCAG 2.2.2) |
| Lightbox | Radix `Dialog` (full-screen sheet), scrim `overlay`, image `object-contain`, close (X + Esc + "Close" text on ≥md), arrows + ←/→ keys (swap in RTL), pinch/double-click zoom with explicit +/− buttons (2.5.1), counter, caption = alt text; focus trapped and returned to the thumb that opened it. Open: fade+scale 0.98→1 `base`; none under reduced motion |
| Review media | separate "Photos from reviews" tab/row below, with "from a verified buyer" labels; not mixed with catalogue images |
| States | loading (stage skeleton, thumbs skeleton), single image (hide thumbs/arrows), no image (placeholder + "No photos yet"), image-error per slide (placeholder, stays selectable), processing (badge) |
| RTL / i18n | thumbs column sits on inline-start; arrows and swipe direction mirror; counter uses localised digits |
| A11y | region `role=region aria-roledescription="gallery" aria-label="{name} photos"`; every image has meaningful `alt` (catalogue alt from model; fallback `{name} – photo {n}`); no information only in image |

## Summary panel
Brand + name `text-h1`; Stars + aggregate "4.6" `text-h2 tabular-nums` + "{n} reviews" link to `#reviews`; TrustBand (v2, restyled `bg-subtle`, ShieldCheck); price/meta; actions: primary "Write a review" (`primary`, 44px), secondary "Add to compare" (`aria-pressed`), icon Save with text. Verified-share + last-moderation line.

## Rating histogram (`RatingHistogram`)
| | Spec |
|---|---|
| Layout | left: big average in `text-h1 tabular-nums` + Stars + "{n} reviews"; right: 5 rows (5→1). Row = button-like link filtering reviews: label "5 stars" (`text-small`, min-w for +40 %), bar track `bg-subtle` height 0.625rem `radius-full` with 1px `border`, fill `star` (≥3:1 on track and `surface`), count + percent `tabular-nums` `text-small text-text-muted` (min-w, never truncated) |
| Interaction | Each row is `<button aria-pressed>` "Show {n}-star reviews ({count})"; selected row: label `font-semibold` + `primary-subtle` row bg + check icon; "Clear filter" link. Updates results count in `role=status` |
| Motion | fills grow 0→value `slow` `ease-enter` once on first view (IntersectionObserver); reduced motion: final state, no animation |
| States | loading skeleton bars; no reviews: empty histogram (all tracks, 0%) + "Be the first to review"; zero-count rows still shown, dimmed via text only (`text-muted`), not opacity (contrast) |
| RTL | bars fill from inline-start (`ms-0`, width %); label side swaps; numbers `<bdi>` |
| A11y | the whole figure has a table alternative: `<table class="sr-only">` or "View as table" toggle with caption; percent also in text so colour/length is never the only signal |

## AI summary card (`AiSummaryCard`, ADR-0034 D12)
| | Spec |
|---|---|
| Container | placed under the summary panel / above reviews. Wrapper `p-px radius-2xl gradient-brand` (the 1px edge is decorative), inner `surface` `radius-[calc(var(--radius-2xl)-1px)]`, padding `p-5 md:p-6`, `elevation-1`. **Text always on `surface`**, never on the gradient |
| Header | Sparkles icon in `accent-subtle` circle + `text-h3` "AI summary" + `accent-subtle` badge "Generated by AI" (text required: AI disclosure) ; end: info button opening Popover "How this summary is made: based on {n} verified reviews, updated {date}, may contain mistakes" |
| Body | 2–3 sentence summary `text-body max-w-reading`; **Pros** and **Cons** lists (Plus/Minus icons, ≤4 each, plain text); "Based on {n} reviews · {verifiedShare}% verified · updated `<time>`" `text-small text-text-muted` |
| Actions | "Was this helpful?" thumbs (toggle buttons with text), "Report a problem" link; "Show reviews that support this" scrolls/filters to cited reviews (cited sentences have a footnote button "Source reviews (3)") |
| States | loading/generating: skeleton + `role=status` "Generating summary…" (never fake streaming text); not enough reviews (<N): `bg-subtle` panel "Not enough reviews for a summary yet ({n} of {min})"; stale (>30d / many new reviews): warning chip "May be out of date" (`warning`/`warning-bg`, icon + text); failed: card hidden entirely (no error to shoppers; staff see reason); suppressed by moderation: hidden; locale mismatch: summary language label "Summary in English" + `lang` attr |
| Motion | none on content; skeleton shimmer only; appearing: fade `base` |
| Contrast | `text`/`text-muted`/`link` on `surface` (gated); `on-accent-subtle` on `accent-subtle` (gated); gradient edge decorative (non-text) |
| RTL / i18n | summary text has `lang` + `dir=auto`; badges wrap; no fixed heights |
| A11y | `<section aria-labelledby>`, h3 inside page h2 "Reviews overview"; AI content labelled in text for SR ("Generated by AI"); popover Esc-dismiss, focus returns; thumbs `aria-pressed` |

## Reviews list (below)
Filters/sort (v2 02, restyled: Chips `primary-subtle` when active, Sheet drawer on <md), ReviewCard (02), pagination (existing). Results count `role=status`.

## Theme / responsive checks
Both themes: stage frame ring visible on white product photos in dark; histogram fill `star` 3:1 vs track in both; AI card edge visible in both (gradient stops light/dark sets). 320px: thumbs scroll row, histogram labels stack above bars if "5 stars" label +40 % wraps.
